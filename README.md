# 🛒 Customer Shopping Behavior Analysis

## 📌 Project Overview

This project analyzes customer shopping behavior using transactional data from **3,900 customer purchases** across multiple product categories. The objective is to identify spending patterns, customer segments, product preferences, and subscription trends that can help businesses make data-driven decisions.

The project combines **Python**, **MySQL**, and **Power BI** to create a complete data analytics workflow, from data cleaning and transformation to business analysis and dashboard visualization.

---

## 🎯 Objectives

* Understand customer purchasing behavior
* Identify high-value customer segments
* Analyze subscription and discount usage patterns
* Discover top-performing products and categories
* Generate actionable business recommendations

## 🔄 Data Cleaning & Preparation

### 1. Data Loading

* Imported dataset using Pandas
* Performed initial inspection using:

  * `df.info()`
  * `df.describe()`

### 2. Missing Value Treatment

* Identified missing values in the `review_rating` column
* Imputed missing ratings using the median rating within each product category

### 3. Data Standardization

* Renamed columns to snake_case format
* Improved readability and consistency

### 4. Feature Engineering

Created new features:

#### Age Group

Customer ages were grouped into meaningful age categories.

#### Purchase Frequency Days

Derived numerical purchase frequency metrics for analysis.

### 5. Data Consistency Checks

* Verified redundancy between:

  * `discount_applied`
  * `promo_code_used`
* Removed redundant columns where appropriate.

### 6. Database Integration

* Connected Python pipeline to PostgreSQL
* Loaded cleaned data into database tables for SQL analysis

## 📈 SQL Business Analysis

The following business questions were answered using PostgreSQL:

### 1. Revenue by Gender

* Compared total revenue generated by male and female customers.

### 2. High-Spending Discount Users

* Identified customers who used discounts but spent above average.

### 3. Top 5 Products by Rating

* Ranked products based on average customer review ratings.

### 4. Shipping Type Analysis

* Compared average purchase values between Standard and Express shipping.

### 5. Subscriber vs Non-Subscriber Analysis

* Evaluated:

  * Average spend
  * Total revenue contribution

### 6. Discount-Dependent Products

* Found products with the highest percentage of discounted purchases.

### 7. Customer Segmentation

Classified customers into:

* New Customers
* Returning Customers
* Loyal Customers

based on purchase history.

### 8. Top Products by Category

* Identified the top 3 most-purchased products within each category.

### 9. Repeat Buyers & Subscription Trends

* Analyzed whether frequent purchasers are more likely to subscribe.

### 10. Revenue Contribution by Age Group

* Measured revenue generated by different age segments.

## 🔍 Key Insights

* Subscription customers contribute significantly to overall revenue.
* Loyal customers generate higher lifetime value.
* Certain products rely heavily on discount-driven sales.
* Express shipping users tend to spend more per transaction.
* Age groups contribute differently to revenue generation.
